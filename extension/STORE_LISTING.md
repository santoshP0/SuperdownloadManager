# Store Listing — Super Download Manager Extension

## Short description (132 chars max)
Send downloads to Super Download Manager for faster parallel downloading. Works automatically — no setup needed.

## Full description
Super Download Manager Extension connects your browser to the Super Download Manager desktop app.

**How it works:**
When you click any download link (.zip, .exe, .mp4, .pdf and 30+ other formats), the extension automatically sends it to Super Download Manager instead of using the browser's slow built-in downloader.

Super Download Manager splits each file into multiple parallel streams — downloads finish significantly faster.

**Features:**
- Automatic — works silently in the background, no clicking required
- Smart — only captures real download files, ignores web pages and images
- Safe fallback — if the desktop app isn't running, your browser downloads the file normally
- On/Off toggle — pause capturing any time from the toolbar icon

**Requirements:**
Super Download Manager desktop app must be installed and running.
Download it free from: https://github.com/santoshP0/superdownloadmanager
